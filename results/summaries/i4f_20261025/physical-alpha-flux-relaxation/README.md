# Experimental physical-time water/flux damping

This is the physical-time implementation tested after the [fixed-state diagnosis](../alpha-flux-relaxation/README.md). It is experimental, default-off, and not yet an adopted or validated apparatus solver. It blends both water fraction and its actual MULES water flux after the candidate solve and before the normal phase/mixture reconstruction; stock mass-flux reconstruction then uses the applied flux. Old-time histories are not blended.

The supported path is static-mesh Euler with MULESCorr, one alpha corrector, one alpha subcycle and no previous-correction blend. At weight one the helper bypasses its snapshots/updates. The original solver, candidate default-off and candidate explicitly enabled at weight one produced byte-identical declared endpoint fields in a single 12 µs step. The captured scope is 15 native fields plus uniform/time, 16 members total; a historical boolean name in the raw proof overstates that count if read literally.
