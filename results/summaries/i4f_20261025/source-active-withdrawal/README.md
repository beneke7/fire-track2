# Sealed-channel predictor-source diagnostic

This compact packet records an exploratory OpenFOAM v2512 comparison of the cached predictor `Sp` coefficient alone versus cached `Sp + div(U)` in the alpha equation. Both settings were run on 60-, 120-, 240- and 480-cell one-dimensional sealed gas/water channels, from the same 1.2 MPa, 293.15 K cold inputs, to 0.4 s with 1,600 fixed steps. Within each resolution, the paired input manifests differ only in `system/controlDict`'s full-source switch.

The source is a private prototype patch with a pinned build record; it is not a released solver change. The water model is constant-density, the turbulence model is laminar with `Pr = 10^9`, and the geometry is a reduced channel. This comparison cannot establish the source term's effect in the apparatus, nor serve as solver validation. The analysis reports native field checkpoint differences and the prototype's discrete local alpha-equation residual. The separate RP-audit follow-up records the predictor-step alpha-equation residual `R_P`; this is not a pressure-field residual.

At 0.4 s the gas-pressure and gas-temperature errors relative to the same-volume adiabatic reference decrease across the four grids for both modes. The coarsest-to-finest errors are 2.92% to 0.88% for pressure and 2.91% to 0.86% for temperature. This is a trend over these meshes, not a formal grid-convergence estimate. In the 60/120/240/480-cell pairs, full-source minus Sp-only gas pressure differs by about 6.71/10.05/9.87/12.05 Pa, and integrated water outflow histories match within each pair. `grid-trend.png` plots the pressure and temperature errors and absolute water-volume balance residual normalized by the initial 80 mL liquid volume; `grid-trend.csv` contains both the SI residual in m³ and its normalized value. Maximum native checkpoint differences in the original 60/120 pair were 10.06 Pa in pressure, 0.0257 K in temperature and 0.00158 in phase fraction. These are observations, not acceptance tolerances. `prototype-build-result.json` predates the initial four runs; its statement that the full-source mode had not yet been run describes the build checkpoint, while the execution and analysis files record the subsequent runs and refinements.

The n=120 RP-audit follow-up added passive logging for 3,200 predictor alpha records and 3,200 full-source records. Its 0.4 s native endpoint field hashes match the uninstrumented full-source run exactly, and the full-source diagnostic records also match. The reported `R_P` maximum is 1.39e-12 s⁻¹ and its volume-L1 magnitude is at most 1.82e-17 m³/s in this run. These are discrete alpha-equation diagnostics; the audit does not report a pressure-field residual. See `rp-audit-summary.json` and its patch/build/source locks.

All eight grid/source containers and the separate n=120 audit container exited normally at 0.4 s and saved native fields. The included data files are compact derived outputs; raw fields, full solver logs, and binaries remain in the ignored source run bundles referenced by the execution summaries.
