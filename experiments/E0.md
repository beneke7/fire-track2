# E0: analytical foundation

Evidence class: analytical verification of diagnostics and elementary kinematics.
This record is declared during initialization before accepting the first E0 run.
It supplies no CFD, breakup, drag, evaporation, foam or field validation evidence.

## Acceptance criteria

Tests use independently computed synthetic quantities in SI units. Exact counts,
indices and zero/no-strip cases must match exactly. Floating-point analytical
identities should agree to absolute/relative tolerance of `1e-12` where unit scales
are order one; larger values may use `1e-10` absolute roundoff allowance. These are
arithmetic checks, not tolerances for future CFD. Tests document any scaled bound.

| Check | Independent expectation |
| --- | --- |
| Constant inlet | `M = rho * A * abs(v dot n) * T`; changing tangential speed does not change flux |
| Ballistic flight | Positive root of `z0 + vz*t - g*t²/2 = 0`; no drag or wind |
| Coordinate mapping | Aircraft origin at absolute impact time plus aircraft-frame displacement; release time is not omitted |
| Weighted deposition | Sum of cell masses plus outside-map landed mass equals total impact weights |
| Strip scoring | Area-weighted threshold coverage across the prescribed width; split intervals remain split by a failing section |
| Dose cap | Useful credit is the threshold mass in qualifying cells of the chosen interval, independent of excess dose |
| Partial cells / nonuniform grid | Geometry uses exact edge overlap and physical interval length, not cell counts |
| Mass ledger | Mutually exclusive compartments close to total released mass |
| Geometry arithmetic | Independently evaluate the Restás ellipse/rectangle example when source dimensions have been verified; no fourfold conclusion from shape alone |
| Repeatability and provenance | Repeated scientific arrays/check values agree; manifests can differ in time and run ID; existing output directories are rejected |

For uniform cell density, clipping boundary cells assumes that density is constant
within a cell. Refining the map is required before threshold claims about actual
deposition. Numerical E0 tests use this explicit representation.

## Execution budget and decision

Run `make check` followed by `make e0`; one CPU thread is enough for the E0 bundle.
The unit suite may include brief subprocesses to verify resource limits, timeout
handling and GPU-lock serialization without performing GPU computations.
Use less than 1 GiB RAM and less than one minute for the analytical bundle.

Raw artifacts are written under `results/runs/`. The orchestrator records the
accepted result and remaining E0 coverage in `docs/STATUS.md` after independent
review. Passing the implemented analytical checks does not release E1 until its
source conditions and CFD solver readiness are established.
